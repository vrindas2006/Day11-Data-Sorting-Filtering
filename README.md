# Day 11 – Data Sorting & Filtering

## 📌 Project Overview

This project was completed as part of my **Data Analytics Internship**.

The objective of this task was to practice basic data sorting and filtering techniques using the **Sample Superstore dataset** in Microsoft Excel.

The project focuses on organizing data, applying filters, analyzing sales performance, and answering basic business questions.

## 🛠️ Tools Used

- Microsoft Excel
- Sample Superstore Dataset
- PivotTable
- Sorting and Filtering
- Excel Formulas

## 📊 Tasks Performed

### 1. Data Sorting
- Sorted sales data from largest to smallest.
- Used sorting to identify high-value sales records.

### 2. Data Filtering
- Applied filters to the dataset.
- Filtered records based on specific categories and regions.

### 3. Multiple Filters
Applied multiple filters simultaneously, including:
- Category = Technology
- Region = West

### 4. PivotTable Analysis
Created PivotTables to analyze:
- Total sales by Region
- Total sales by Category
- Total sales by Segment

### 5. Business Questions

The following questions were answered using the dataset:

1. Which region has the highest total sales?
2. Which category has the highest total sales?
3. Which segment has the highest total sales?
4. How many records have sales greater than $1,000?
5. How many records have negative profit?

## 📈 Key Results

| Analysis | Result |
|---|---|
| Highest Sales Region | West |
| Highest Sales Category | Technology |
| Highest Sales Segment | Consumer |
| Records with Sales > $1,000 | 468 |
| Records with Negative Profit | 1,871 |
